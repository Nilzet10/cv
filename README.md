# Nidha's Events: website demo

A one-page demo site for **Nidha's Henna Designs**, **Dream Tea Cart** and **Lit DJ Entertainment** (Iselin, NJ).

- `index.html`: the whole site (HTML, CSS and JS in one file, no build step). Open it in any browser.
- `print/`: printable QR code (`qr-nidhasevents.png` / `.svg`) and a 4×6 booking card (`booking-card-4x6.pdf` / `.png`). Kept in the repo, not published on the site.
- `PUBLISHING.md`: step-by-step guide to buying a domain, hosting the site for free, and making the booking form work.
